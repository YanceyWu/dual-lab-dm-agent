# Sanitized Research Input

Store only manually reviewed, policy-approved abstractions from the company
environment, such as anonymous architecture profiles, table identifiers,
relationship maps, call graphs, structured pseudocode, and feedback cards.

Do not store screenshots, source code, actual SQL, real schema names, real file or
class names, records, credentials, internal URLs, project names, employee names,
customer information, or proprietary business values.

Prefer `UNKNOWN` to an unsafe or speculative detail.
